# 首页连续故事 · 本轮审核说明

本轮按已确认的叙事顺序实施。所有工程修改、Blender 输出和浏览器审核截图均留在当前仓库；最新版项目书仅作为文献依据读取，未放进网站公开资源。

## 可以直接审核的内容

- 开场保留中央恒星与轨道，数据地球和校园星球各占一个轨道位置。随后放大数据地球，再进入日常生活、胃肠、黏膜与工程菌。
- 数据地球使用真实世界轮廓与低饱和浮雕配色；可以切换 1990 / 2019 年、选取地区。选取地区后镜头将其转到可见方向。选择、长按和滚动均可使用。
- 图书馆近景结束后先拉回，再让星球在屏幕平面内转动，随后出现实验楼。两栋建筑保持刚体比例；局部地形平缓连接球面，不再把整个立面弯曲。近景照片沿用仓库内的南校区参考材料。
- 实验室为最后的探索空间。到达后滚轮用于缩放，顶部回放按钮重新开始故事；设备探索与五个专题入口同时可用。
- Simple mode 是新绘制的 SVG 实验室：设备位置来源于同一份房间布局，可点选设备和文献。没有使用生成图片作为整间实验室底图。
- 全景墙面保留三篇核心文献，阅读窗口提供八篇文献及研究语境。学校、队伍与项目标识使用统一展框；校徽采用圆形裁切，队标使用已有透明素材。
- 前方 iGEM Lab 标识矮墙与左侧矮墙接合，并统一高度与材质。

## 模型代表什么

Blender 母文件与两个审核角度的渲染保存在 `outputs/blender/`；网页使用 `public/assets/models/` 中的 GLB。

- `digestive-system`：连续的食管—胃—十二指肠—小肠—大肠关系。胃采用平滑连续半径；小肠采用有深度变化的连续曲线；大肠保留升、横、降、乙状段与直肠，另有盲肠和阑尾。器官比例、盘曲数量为叙事简化。方向说明与标签位于“Inside the gut”。
- `colon-section`：纵向打开的结肠段，切面分别显示黏膜、黏膜下层和两层肌层。96 个隐窝开口直接组成黏膜内表面，凹陷没有被另一层实体表面封住。浅色细胞表示杯状细胞，淡绿色细线表示黏液层；没有把结肠画成小肠绒毛。层厚和隐窝尺寸为便于观察而放大。
- `engineered-ecn`：革兰阴性杆菌剖面，区分外膜、肽聚糖、内膜、拟核、质粒与核糖体。紫色膜旁标记表示 PspA；黄色标记表示 Elafin；外部暖色与紫色几何标记分别表示 ROS 和胆汁酸环境。这些符号不是分子结构预测。
- Elafin 释放从多个膜边缘位置逐渐扩散；生产与外部可用性分别叙述。动画不引入新的分泌装置，也不把长按动作表达成给药开关。退出先改变信号，再改变 PspA 标记，最后显示群体逐渐减少；间隔不对应实测半衰期或清除率。
- `clean-bench` 保留既有 Blender 外壳和支架，恢复玻璃原有透明度，近景可检查连续台面、侧衬、后衬、玻璃导轨和连接件。

解剖关系参考 [NIDDK 消化系统说明](https://www.niddk.nih.gov/health-information/digestive-diseases/digestive-system-how-it-works)。本轮机制画面依据 VER16.9 的设计逻辑，仍以示意与待验证设计呈现。

## 数据与文献依据

地球使用 [GBD 2019 的 IBD 负担分析](https://doi.org/10.1136/bmjopen-2022-065186)表 1 中的 21 个地区估计，指标为每十万人年龄标准化患病率，显示 1990 与 2019 两个年份。图例固定一致，地区卡保留 95% 不确定区间。国家边界提供位置背景，不表示逐国或城市精度；小岛以颜色保留数值，减少浮雕高度以免成为视觉尖刺。底图为 [Natural Earth 1:50m 国界](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries-2/)。

三篇全景文献为项目书的 [139] Rubens 2016（感应）、[131] Wang 2021（膜能量与存活）、[25] Teng 2022（EcN 与 Elafin）。阅读窗口另列 [7] Begley、[137] Inda-Webb、[149] Andersen、[3] Simmonds 与 [39] Hoffmann / Cai。每条有原文链接、项目关联和证据适用范围；不把异种、需氧或其他培养条件的结果直接当成本项目的参数。

地区归属参照 [WHO 所列 GBD 21 地区对照表，第 39 页](https://www.who.int/docs/default-source/cardiovascular-diseases/19tlgh0153-appendix.pdf)。这里采用统计分区：例如以色列属于 Western Europe，伯利兹属于 Caribbean；它们不是按地理邻近关系临时分组。

## 验证与使用

本地预览：`http://127.0.0.1:5174/syphu-china/`。

- `npm run build`：TypeScript 与生产构建。
- `npm run lint`：代码检查。
- `npm run test:layout`：房间边界、设备接触、碰撞和通道。
- `node scripts/validate-journey.mjs`：镜头连续、建筑互斥与原有设备约束。
- `node scripts/validate-blender-assets.mjs`：GLB 几何、尺寸、语义部件和材质合批。
- `node scripts/check-continuous-story.mjs`：桌面与手机截图、年份选择、点击/长按/键盘、设备弹窗、文献筛选、二维模式、回放、专题路由和减少动态效果模式。截图输出到 `outputs/story-review/`。

专题入口沿用现有页面：Design 指向项目介绍，Safety 指向 Safety and Security。专题内的实验结果不由首页动画补写。
